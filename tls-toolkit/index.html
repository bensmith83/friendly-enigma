Protocol Steps

  1. ClientHello - Client initiates connection, sends supported cipher suites and TLS versions
  2. ServerHello - Server selects cipher suite and TLS version, sends certificate
  3. Certificate - Server sends its certificate chain for authentication
  4. Certificate Verify - Server proves it owns the certificate's private key
  5. Finished (Server) - Server confirms all handshake messages
  6. Finished (Client) - Client confirms, session keys established
  7. Encrypted Data - Secure communication established!

About Mermaid

Mermaid is a JavaScript-based diagramming and charting tool that renders Markdown-inspired text definitions to create and modify diagrams dynamically.

Supported Diagrams

  • Flowcharts
  • Sequence diagrams
  • Class diagrams
  • State diagrams
  • ER diagrams
  • Gantt charts
  • Pie charts
  • Git graphs

Quick Tips

  • Start with a diagram type (e.g., graph TD)
  • Use --> for connections
  • Use [ ] for boxes, { } for diamonds
  • Add |text| for edge labels
  • Use %% for comments
